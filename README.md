# 501 Movie Directors — unofficial Stremio add-on

An independent, free, **catalogue-only** Stremio add-on inspired by Steven Jay Schneider's *501 Movie Directors* (2007). Select one of the book's **501 director entries** and see that filmmaker's IMDb filmography in **newest-first** order. Where the book treats a directing pair as one entry, the catalogue combines their directing credits without duplicates.

The website is based on the approved black-and-white/bright-yellow design. **Hitchcock remains in the hero illustration; there are no portrait photographs in the director selection or director information section.** Only movie posters appear in the filmography.

This is **not** an official product of IMDb, Stremio, the book's editor, or its publishers. This add-on supplies film lists, not video or streams; other installed Stremio add-ons provide stream links.

## Download/upload and publish

Suggested new **public** GitHub repository name: `501-movie-directors` (do not mix these files into your existing Top Rated Films repository).

1. Create the repository on GitHub with **no** autogenerated README, `.gitignore` or licence (the ZIP includes the README).
2. Open the ZIP, select its **contents** and upload to the **root** of the new repository. **Do not upload the enclosing directory.** The root must contain `build.js`, `data/`, `docs/`, `README.md`, and `.github/`.
3. **Check the hidden workflow:** browse to `.github/workflows/update.yml` in the GitHub repository. If that file was not uploaded, select **Add file → Create new file**, type `.github/workflows/update.yml` as the filename, and paste in its contents from the ZIP.
4. Open **Settings → Pages** and select **GitHub Actions** for the build/deployment source.
5. Open **Actions → Rebuild and publish 501 directors → Run workflow** (branch `main`). The workflow will download IMDb's datasets, generate film lists for all directors, and deploy them as a static website. The first run can take a while because it reads four large IMDb files. Do not expect instant publication.
6. Wait until **both** `rebuild` and `deploy` are green. Your website will usually be at:

   `https://YOUR_USERNAME.github.io/501-movie-directors/`

7. Open that page. Click **Install Add-on for Stremio**, or **Copy Stremio Link** and paste the manifest URL into Stremio's add-on installation box.

**You do not need to hard-code your GitHub username or repository name**: GitHub Actions supplies `GITHUB_REPOSITORY`, and `build.js` produces the correct manifest asset URLs automatically. The website's two install buttons also calculate its actual deployed address.

After the initial successful publication, updates run **weekly** on Sunday 18:23 UTC (early Monday in Melbourne). The scheduled rebuild **publishes directly to GitHub Pages**; it does **not** attempt to commit generated files back to the repository (which caused permission problems with an earlier add-on).

## What Stremio shows

- One catalogue: **501 Movie Directors**.
- **All 501 director choices are in the original book’s numbered order**, beginning with **#001 Georges Méliès**, **#002 August Blom**, **#003 Edwin S. Porter**, through **#501 David Gordon Green**. The website shows the entry numbers, supports searching by name or number, and lets you scroll through the complete list. **Hitchcock remains the website’s default preview** without being moved to the top of the selection list.
- The director is a **required** selection, so there is no unfiltered `None` choice.
- Films are arranged **latest to earliest** by IMDb release year. Where films share a year, the higher vote count comes first.
- The catalogue is paged (100 items per page), allowing directors with long feature-film careers to have their entire eligible list.
- IMDb film types included: **movie** and **tvMovie** only. **Excludes short films, music videos, television series, miniseries, episodes, other video-only credits and adult titles.** Titles with a known runtime of **40 minutes or less** are also excluded, including any short-form music videos miscoded as movies. A film with unknown runtime is retained if IMDb calls it `movie` or `tvMovie`. **Feature-length music films and documentaries remain included.** Titles with future **release years** are omitted, but IMDb provides only years, so a future premiere within the current year may appear.
- IMDb movie ratings are shown when the IMDb rating dataset contains them. Poster images are supplied by the independent Metahub image endpoint; titles without a poster show a typographic placeholder on the website.

**All countries and languages are eligible, including Indian directors and Indian-language films (with no release-year restriction).** There is no IMDb minimum rating or vote-count threshold. Directors who made only shorts may have no eligible feature films under these rules.

## Data and automatic generation

`data/directors.txt` contains the book's 501 named **entries** in book order, checked against a publicly available book index and the user-provided IMDb list. Some book entries are filmmaking **pairs**, so 501 entries can correspond to more than 501 individual people.

`build.js` streams these official IMDb **non-commercial** datasets, without API keys or npm dependencies:

- `name.basics.tsv.gz` — resolves director names to IMDb people IDs.
- `title.crew.tsv.gz` — finds their directing credits.
- `title.basics.tsv.gz` — keeps feature films and standalone TV movies; filters short films, music videos and TV programmes using title types and available runtimes.
- `title.ratings.tsv.gz` — supplements film cards with IMDb ratings.

No IMDb list scraping is required: `data/directors.txt` is included in the repository so an IMDb list-page 403 response does not break the build. When matching a filmmaker whose IMDb display name differs from the book name, check and edit `ALIASES` in `build.js`. After a successful build, `docs/data-health.json` (in the build artifact, not automatically committed back to GitHub) contains the director name resolutions and entries without films.

`build.js` intentionally fails the build if fewer than 400 of the 501 book entries have at least one matched IMDb directing credit. That means a broken dataset or severe name-matching problem cannot silently replace the existing working GitHub Pages site. Some individual directors may still need name-alias corrections.

IMDb's non-commercial datasets are licensed for **personal and non-commercial use**. Review their [terms](https://www.imdb.com/interfaces/) before public redistribution or commercial use. The original 501-director selection is attributed to the published book; this project reproduces names, **not** the book's essays or biography text. The still of Hitchcock comes from the design supplied and approved for this project.

## Development / optional tests

Requirements: **Node.js 22+** (no `npm install`).

- `node --test tests/build.test.js` — tests the 501-entry index, Indian-language inclusion, pair handling, IMDb matching, film/TV film filtering, book-order selection and newest-first sorting using small local mock IMDb datasets.
- `node seed-preview.js` — recreate an offline Hitchcock preview.
- `node build.js` — download the real IMDb datasets and regenerate all director filmographies (network connection required).
- `IMDB_DIR=/path/to/gz-datasets node build.js` — use local copies of the four `.tsv.gz` files.

When testing against fixtures use `OUT_DIR=/tmp/501-test` and `MIN_MATCHED_ENTRIES=0` so you do not overwrite the live catalogue and do not enforce the full 400-entry success threshold.

## Troubleshooting

**Workflow fails at `Generate directors and filmographies from IMDb`:** open **Actions → failed run → rebuild**, expand that exact step and read the final error lines. Dataset downloads can fail transiently. Retry once, then share the expanded log. Do not create a new repository or reupload everything merely because a run fails.

**Workflow fails at `Deploy to GitHub Pages`:** confirm **Settings → Pages → Source: GitHub Actions**, then confirm that GitHub Pages publishing is permitted in the repository.

**Website shows only Hitchcock preview / other directors have no films:** the full IMDb workflow has not succeeded. Confirm both jobs are green.

**One filmmaker has no titles after a successful run:** inspect the `data-health.json` build output or the last lines of the build logs; the person's name may need an alias in `build.js`.

**Film posters are missing:** poster images come from Metahub, not the IMDb TSV datasets. Missing images do not mean that the Stremio film catalogue failed.
